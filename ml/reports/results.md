## 2. Мэдлэг хянах загвар — BKT (FR-08)

Өгөгдөл: ASSISTments 2009 (pyBKT хувилбар). Түүхий 525,534 мөрөөс skill-гүй 78,690,
давхардсан (order_id, skill) 121,207 мөрийг хассан → 325,637 мөр, 4,151 сурагч, 110 skill.
Сурагчаар (user_id) 80/20 хуваасан: train 259,762 мөр / 3,320 сурагч,
test 65,875 мөр / 831 сурагч. Сурагч давхцаагүйг кодонд assert-аар шалгадаг.

| Метрик | Утга |
|---|---|
| **AUC (test)** | **0.7237** (зорилт ≥ 0.7 — ✅ хүрсэн) |
| RMSE (test) | 0.4353 |
| Baseline AUC (skill-ийн дундаж зөв хувь) | 0.6273 |
| Сургалтын хугацаа | 360 сек (CPU) |

`config/bkt_params.yaml`-д хадгалсан анхны параметр (skill-үүдийн медиан, IQR):

| Параметр | Медиан | IQR (25–75%) |
|---|---|---|
| prior | 0.6673 | 0.5197 – 0.8008 |
| learn | 0.1431 | 0.0734 – 0.3023 |
| guess | 0.1463 | 0.0469 – 0.3368 |
| slip | 0.2316 | 0.1554 – 0.2922 |

**Яагаад медиан вэ:** манай системд хэрэглэгчийн хариултын түүх хараахан байхгүй тул T01–T10 сэдэв бүрт
тусгайлан параметр сургах боломжгүй. ASSISTments-ийн математикийн skill-үүдийн медиан нь
"ердийн математикийн ур чадвар" ямар хурдаар эзэмшигддэг тухай бодит өгөгдөлд суурилсан, хэт утгад
(outlier) тэсвэртэй анхны таамаг болно. Систем ашиглагдаж эхэлсний дараа сэдэв тус бүрээр дахин сургана.

## 4. OCR (NFR-05: ≥ 85%)

**Өгөгдөл хүлээж байна.** `data/own_images/`-д зураг ↔ `.tex` хос олдсонгүй. Үнэлгээний скрипт (`ml/ocr/evaluate.py`) бэлэн: зураг бүрийн хажууд ижил нэртэй `.tex` файл (жинхэнэ LaTeX) тавиад `python -m ml.ocr.evaluate` ажиллуулна. Метрик: exact match ба normalized edit distance (хэвийн болгосон LaTeX дээр).
